Emergency Reset

Use this page if the main app won't load due to corrupted data.

⚠️

This will completely reset the app to its initial unused state.

This will:

  • Unload library and collections
  • Remove all folders and organization
  • Reset all filters and settings
  • Clear all app data

Good news: This only clears data from your browser. Your files on disk are safe.

What you can recover:

  • Import backup file → Restore EVERYTHING (books + folders + tags + notes + order + price goals)
  • Import amazon-library.json → Restore books only (lose folders, tags, notes, order, price goals)

💡 Tip: If you have access to the main app, use File → Export Backup first to save your organization before resetting.

## Issues Found During Testing

1. **Thumbtack looked flat** - Missing `::after` shadow element for 3D effect
2. **DEL key propagated** - Deleted books behind modal; fixed with `e.stopPropagation()`
3. **Undo/redo complexity** - Initially implemented, then removed per user feedback
4. **Stale closure** - `modalBook` in keyboard handler was stale; fixed with ref
5. **Ctrl+Z consumption** - Had to always `preventDefault()` to preserve undo stack

## Lessons Learned

1. **Undo/redo for modal edits is complex** - Form-style edits (type, save, close) don't fit the undo model well. Better to treat as committed on save.

2. **React stale closures in event handlers** - Keyboard handlers set up once need refs for state that changes (like `modalBook`).

3. **Always preventDefault for consumed keys** - Even if not acting on a key, prevent default to avoid browser behavior affecting state.

4. **Test keyboard interactions thoroughly** - DEL, Ctrl+Z, Ctrl+A, Ctrl+C all needed attention in modal context.

## Design Decisions

1. **No undo/redo for notes** - Notes are form entries; edit again if needed
2. **Single selection only** - Notes are personal per-book context, not bulk operation
3. **Sticky note styling** - Matches landing page brand element

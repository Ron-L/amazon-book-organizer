# v4.26.0 Post-Mortem - Show Hidden Always Visible

**Release Date:** 2026-01-24
**Duration:** ~20 minutes

## What Was Changed

"Show Hidden" checkbox and filtered book count now visible in collapsed filter state.

## Problem Statement

User frequently toggled Show Hidden but had to expand the filter panel to access it. The book count was visible when collapsed, but Show Hidden was buried.

## Technical Implementation

### Changes (readerwrangler.js v4.22.0)

Replaced collapsed state display (lines 4385-4409):

**Before:**
```
[Filters]    2702 books
```

**After:**
```
[Filters]    Showing: 2571 of 2702    ☐ Show Hidden
```

- Uses same `filteredBooks()` logic as expanded view
- Simplified display (removed copy count to keep collapsed view clean)

## Files Changed

- `readerwrangler.js` v4.21.1 → v4.22.0
- `CHANGELOG.md` (v4.26.0 entry)

## What Went Well

1. **Single iteration** - Implementation worked first try
2. **Consistent with expanded view** - Same format, familiar to users
3. **UX-driven** - User identified the friction point

## Issues Discovered During Testing

1. **Count discrepancy** - "Showing: 2571 of 2702" revealed wishlist books are in `books` array but not in columns. This is expected behavior but became visible with the new format. Added to session checklist to investigate display options.

## Lessons Learned

1. **View toggles should be easily accessible** - If a control is frequently used, it shouldn't be buried under expansion states.

2. **Changing display format can reveal existing data quirks** - The count discrepancy existed before but wasn't obvious until the format changed.

## Design Decisions

1. **Kept "of X" as total books** - Shows complete picture rather than hiding wishlist count
2. **Removed copy count from collapsed view** - Keeps display compact; details available in expanded view

## Mistakes Made

### 1. **Wrong Version Number Initially**

- **Fix**: Pay closer attention to version semantics - bug fix = patch increment

### 2. **First Fix Targeted Wrong Location**
- Fixed import logic when the bug was actually in export logic

## Lessons Learned

### 1. **File System Access API User Gesture Requirements**
- Chrome requires "active user gesture" for `createWritable()`
- Gestures expire after async operations (fetching, processing)
- Solution: Add UI button immediately before file write to capture fresh gesture
- This pattern now exists in both Library Fetcher and Collections Fetcher

### 2. **Export/Import Data Integrity**
- Export should not create data structures that imply data exists when it doesn't
- `fetchDate` in collections section implied fresh data even when `booksWithCollections: 0`
- Fix: Only include collections section in export when `collectionsStatus.loadStatus !== 'empty'`

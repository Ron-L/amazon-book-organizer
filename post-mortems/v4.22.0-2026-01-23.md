# Post-Mortem: v4.22.0 - 2026-01-23

## Summary
Fixed wishlist price parsing crash and improved price/description extraction in fetchers.

## What Changed
- **readerwrangler.js v4.19.0**: Added `parsePrice()` helper to convert string prices ("$5.99") to numbers during load
- **amazon-wishlist-fetcher.js v1.4.0**: Added price and description extraction from product pages
- **series-page-fetcher.js v1.1.0**: Improved price extraction with `.ebook-price-value` selector, added data completeness summary

## Root Cause
The loader passed `currentPrice` through as-is from JSON, but fetchers stored it as a string (e.g., "$5.99"). The UI code called `.toFixed()` on it, which only works on numbers, causing a crash.

## Discovery Path
1. User added Destroyer series books via series-page-fetcher
2. Some books had prices, some didn't (Amazon API inconsistency)
3. App crashed on load with "book.currentPrice.toFixed is not a function"
4. Investigation revealed price was stored as string, not number

## Debugging Process
1. Traced data flow from fetchers → JSON → loader → UI
2. Found fetchers stored prices as strings like "$5.99"
3. Found loader didn't parse prices, just passed them through
4. Added `parsePrice()` helper to normalize during load

## Additional Improvements Made
1. **Wishlist fetcher**: Added price/description extraction (wasn't capturing before)
2. **Series fetcher**: Added `.ebook-price-value` selector for newer Amazon layout
3. **Series fetcher**: Added data completeness tracking and summary in console/toast
4. **Created `.private/destroyer-gap-filler.js`**: One-off script to fetch books #101-149 missing from Amazon's series metadata

## Investigation: Missing Price Data
- Some books in Amazon's series API response have no price data at all (no `.slot-price` element)
- This is an Amazon limitation, not a selector issue
- Data completeness summary now informs users which books are missing data
- Library Fetcher can be used to fill in missing data later

## Lessons Learned
1. **Type consistency**: Fetchers should store prices as numbers, not strings with currency symbols
2. **Defensive loading**: Loader should normalize data types during import
3. **Version discipline**: Increment minor version when first modifying a file, not just append ".a" to existing version
4. **Keep letter suffixes**: Don't finalize file versions until release (may need to circle back)

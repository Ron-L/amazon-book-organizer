**Release Date:** 2026-01-13

## Summary

Made the landing page mobile-friendly. The hero section was sticky on desktop (nice for scrolling), but on mobile it consumed ~50% of the viewport and couldn't be scrolled past. This release fixes mobile portrait and landscape layouts.

## What Changed

### Portrait Mobile (max-width: 768px)
- Hero: Changed from `position: sticky` to `position: relative` so it scrolls
- Reduced hero padding from 64px to 32px
- Replaced desktop "Get Started" section with mobile-specific content:
  - "Best on Desktop" message explaining bookmarklet requires desktop
  - Expandable "How to View on Mobile" with cloud sync instructions
- Comparison slider scales to full viewport width

### Landscape Mobile (max-height: 500px + orientation: landscape)
- Hero uses reduced padding (16px)
- Logo and sticky note repositioned using center-relative positioning (like desktop)
  - Logo: `left: 50%; margin-left: -350px; width: 120px`
  - Sticky note: `left: 50%; margin-left: 250px; width: 120px`
- Full-width containers with `overflow-x: hidden` to prevent horizontal scroll
- Bullet list indentation fixed

### Additional Updates
- Moved "Improved book cover performance" from Coming Soon to Recent Features (v4.14.0)

## Technical Decisions

### Center-Relative Positioning
Desktop uses `left: 50%; margin-left: Xpx` to position decorative elements relative to the centered content. Initially tried edge-relative (`left: 10px`, `right: 10px`) for mobile landscape, but user feedback was that it looked disconnected from the content. Switched to center-relative to match desktop behavior.

### `<details>` Element
Used native HTML `<details>`/`<summary>` for the expandable mobile sync instructions. No JavaScript needed, works everywhere, graceful fallback.

### Media Query Strategy
- Portrait: `@media (max-width: 768px)` - standard mobile breakpoint
- Landscape: `@media (max-height: 500px) and (orientation: landscape)` - catches rotated phones

## Lessons Learned

1. **DevTools DPR matters**: When simulating mobile, CSS pixels (360x800) are more relevant than physical pixels (1080x2424). Pixel 9A has ~2.5-3x DPR.

2. **Center-relative > edge-relative**: For decorative elements that "frame" centered content, positioning relative to center maintains visual consistency across viewport sizes.

3. **Test both orientations**: Landscape mobile is often overlooked. The `max-height` media query catches rotated phones that portrait-only queries miss.

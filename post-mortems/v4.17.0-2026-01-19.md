# Post-Mortem: v4.17.0 - Wishlist Price Display

**Date**: 2026-01-19
**Version**: v4.17.0
**Duration**: ~1.5 hours (continued from previous session)

## What Was Built

Wishlist Price Display feature enabling users to track prices and find deals on wishlist books:

1. **Price Tag Badge** - Price displayed on wishlist book covers (bottom-left)
   - Gray when above goal or no goal set
   - Green when at or below target price

2. **Price Goal Picker** - Set target prices in book detail modal
   - Preset buttons: $0.99, $1.99, $2.99, $3.99, $4.99
   - Custom button with input field
   - Clear button (×)
   - Confirmation: "✓ Goal: $X.XX or less"

3. **Deals Filter Button** - `🏷️ Deals (n)` in header
   - Shows count of books at or below target price
   - Toggles filter to show only deal books
   - Green when active

4. **Green "View on Amazon" Button** - When book is at goal
   - Shows price in button: "View on Amazon — $X.XX"
   - Green styling instead of orange

5. **Savings Display** - In book detail modal
   - Current price with savings from list price
   - Strikethrough list price with percentage saved

## What Went Well

1. **Design doc was comprehensive** - WISHLIST-PRICE-DISPLAY.md provided clear specs
2. **Incremental implementation** - Built feature by feature with testing between each
3. **UX improvement discovered** - "View on Amazon" button already in better location than spec; enhanced with green styling
4. **Quick iteration on bugs** - Double dollar sign fix caught and resolved immediately

## Issues Encountered

1. **Price badge not showing initially** - Fields weren't mapped from JSON to book object in loader
   - Root cause: New fields (currentPrice, listPrice, priceTrigger, genres) needed explicit mapping
   - Fix: Added field mapping in both v2.0 schema and legacy schema book loaders
   - User had to re-import JSON to update IndexedDB

2. **Double dollar sign in Goal text** - JSX template literal confusion
   - `$${variable}` outputs literal `$` + interpolated value
   - Fix: Used `{'$'}{variable}` pattern

3. **Forgot to commit before testing** (once) - Ground rules reminder helped

## Lessons Learned

1. **IndexedDB caches old data** - When adding new fields, users must re-import to get updated data
2. **Check both book loader paths** - v2.0 schema AND legacy schema need field mapping
3. **JSX dollar signs are tricky** - Use `{'$'}` for literal dollar sign in JSX

# Post-Mortem: 7.7.0 — the investigation release

**Date**: 2026-09-04
**Release**: 7.7.0 (app) / 1.8.0 (mobile) / fetcher v5.3.1 / nav hub v2.1.1, prod+dev — 15 app alphas over three days. F1 single-store consolidation, two echo-push kills, the orphan-machinery repair (sight + honesty), the FORMAT POLICY package, Welcome-screen recovery, two field-telemetry ownership types, and (landed separately mid-cycle) the usage-alert redesign.

The defining event wasn't a feature — it was the day-long live investigation of "13 orphans" that ended with the Amazon library API fully mapped, five bugs dead, and the library proven to match Amazon **exactly** (2801 = 2801). FORMAT-POLICY.md is the never-relitigate record.

## ✅ What worked well

1. **Ron's refusal to accept plausible answers.** The 13 got three convincing wrong explanations in sequence — *deleted on Amazon* (killed by his /yourbooks screenshot), *hidden by Amazon's filter* (killed by his captured page request), *cursor-pagination loss* (killed by its own experiment). Each time the response to "case closed" was a fact that didn't fit, pursued. "Keep the back and forth short — don't get invested in an answer until we're on the same page" should be framed.
2. **Cheap read-only probes beat theory every round.** Console fetches against `kindle-reader-api` settled in minutes what speculation couldn't: `2829 − 2816 = 13` (filter delta), hash-B membership = product-null husks, dual 30/50-page walks byte-identical (pagination exonerated), 15 dupes = sample-then-purchase pairs. Total cost: a handful of GETs.
3. **The numerology trap, survived.** Three unrelated sets of size ~13/15 (false orphans, filter-hidden husks, duplicate records) spent a day masquerading as each other. Naming all three in one table was the move that ended the confusion — worth remembering as a technique.
4. **Policy → code → doc in one day, while the evidence was fresh.** The FORMAT POLICY (capture everything / verbatim or nothing / user-edit precedence / binding-blind verification) shipped complete with its documentation the same day it was ratified — no decay between decision and record.
5. **Small independent branches + a worktree.** The worker branch and fetcher branch landed on their own schedules; the git worktree for fetcher work ended the serving-tree flicker that had briefly put Ron's localhost on the wrong branch the day before.
6. **The closing ceremony as a designed test.** "Next fetch reports 0 orphans" was a prediction with an expected value, and it hit — as did the alerts redesign's "one seed email, then a quiet 7-8 PM window."
7. **Field telemetry paid off again** (ownership types round two: PublicLibraryLending + AudiblePlus classified same-day, no user report needed).

## ❌ What went wrong

1. **The "two different services" claim** — asserted from plausibility (page shows maps, our query doesn't return them ⟹ different APIs), demolished by a captured request showing the same endpoint. Lesson: page-vs-API claims require a captured request, not inference from behavior.
2. **The pagination-loss theory was framed confidently before its test ran.** Credit: it was built falsifiable, with named predictions, and died cleanly. Debit: the confident framing ("the culprit is…") preceded the evidence twice in one day.
3. **alpha.13 shipped a crash in a duplicated code path.** The context-menu Edit duplicates `enterEditMode`'s field-set inline; adding `binding` to one and not the other made every save from that path throw silently. *Enumerate-all-instances applies to setters, not just call sites* — grep for duplicates of any structure you extend.
4. **"App-side-only" data isn't.** The invented `'Kindle eBook'` default was assumed to live only in the app — but backups carry `book.binding`, restores push backups to the relay, and the canonical got seeded with the token, silently blocking the first backfill (0 filled) and resurrecting on every import until an inbound filter (alpha.15) was added. Lesson pair: **any field that enters export/backup travels everywhere**, and **a migration that clears a value must be paired with an inbound filter while any source of truth still carries it**.
5. **A sloppy test prediction cost a round-trip**: "expect hundreds backfilled" (actual: 13, correctly) sent Ron looking for the wrong signal, and "expect a line" without saying *one summary line, not per-book lines* sent him looking again. Expected values in test instructions should be precise about magnitude *and* shape.
6. Two same-day patch releases of fresh code (v5.3.1 on v5.3.0, alpha.15 on alpha.12) — acceptable alpha-cycle churn, but both trace to point 4's missed contamination vector.

## Final thought

This cycle started with "storage is at 678 MB and I got weird alert emails" and ended with a mapped API, a ratified data policy, and an exact-match invariant a fetcher can actually print. The pattern that made it work: every alarming number was chased until it had a *name* — wishlist, sample-pair, husk, echo, token — and once everything had a name, there was nothing left to fear. Honesty features keep being cheaper than the mysteries they prevent.

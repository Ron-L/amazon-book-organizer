# Post-Mortem: v4.21.0

**Date:** 2026-01-22
**Release Type:** Feature

## Summary

Added Series Page Bulk Import feature - one-click import of entire book series to wishlist with gap detection.

## What Changed

### New Features
1. **Series Page Fetcher** - New `series-page-fetcher.js` v1.0.0
   - Uses Amazon's `seriesAsinList` API to fetch all books in single request
   - Parses HTML response to extract book metadata
   - Automatically skips owned books
   - Detects gaps in series numbering and reports missing books
   - Deduplicates against existing library

2. **Navigator Update** - `bookmarklet-nav-hub.js` v1.3.0
   - Loads series fetcher when on series pages (instead of wishlist fetcher)
   - Product pages still use wishlist fetcher for single-book adds

## Technical Implementation

### API Approach vs DOM Scraping

Previous wishlist fetcher used DOM scraping with "Show All" click to load series books. New approach:

| Aspect | Old (DOM) | New (API) |
|--------|-----------|-----------|
| Method | Scrape rendered page | Fetch from API endpoint |
| Reliability | Dependent on page load timing | Single request, consistent |
| Book limit | Whatever page renders | 200 per request |
| Speed | Slower (wait for "Show All") | Fast (~1 second) |

### Gap Detection

Series books often have gaps in Amazon's metadata (e.g., Destroyer series shows 103 books but numbered 1-155 with #101-149 missing).

Detection logic:
1. Extract `seriesPosition` from each book
2. Find max position
3. Check which positions 1-max are missing
4. Format as ranges (e.g., "#101-149")

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Separate fetcher file | Clean separation; future author bibliography fetcher will follow same pattern |
| API over DOM scraping | More reliable, faster, handles large series better |
| Gap detection in Phase 1 | Users need to know about incomplete data immediately |
| Gap filling deferred | Complex feature (search queries, rate limiting) - saved for Phase 2 |

## Known Limitations

1. **No gap filling** - Reports gaps but doesn't attempt to find missing books via search
2. **200 book limit** - API pageSize=200; series >200 would need pagination (rare)
3. **Amazon metadata gaps** - Can't fix Amazon's incomplete series tagging

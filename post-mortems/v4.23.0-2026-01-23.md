# v4.23.0 Post-Mortem - Author Bibliography Import

**Release Date:** 2026-01-23
**Duration:** ~1 session (resumed after compaction)

## What Was Built

### Author Bibliography Import
- One-click import of all Kindle books by an author to wishlist
- Detects author pages via `/stores/.../author/` URL pattern
- Button text changes contextually: "Add Bibliography to Wishlist" on author pages

### Bug Fixes
1. **Cover image extraction** - Fixed selector to match `media-amazon.com` domain (author pages use different CDN than product pages)
2. **Navigation filter** - Filter out footer/navigation items that were being captured as books (e.g., "Amazon Business Card" link)
3. **Cover stats logging** - Added cover count to completeness output alongside price/rating

## What Went Well

1. **User-driven debugging** - User provided actual DOM HTML from Amazon page, which immediately revealed the `media-amazon` vs `images-amazon` domain issue
2. **Diagnostic logging** - Added suspicious entry warnings that caught the navigation footer issue
3. **Incremental testing** - Fixed cover issue first, then caught navigation issue in follow-up test

## Challenges

1. **Amazon DOM inconsistency** - Author pages use different image CDN domain than product/series pages
2. **Spurious entries** - Footer navigation items on author pages have minimal markup (bare `<li>` with `nav_a` links), making them harder to filter than expected

## Technical Decisions

1. **Image selector** - Used dual selector: `media-amazon` (primary for author pages), `images-amazon` (fallback for other pages)
2. **Navigation filter** - Two-prong filter: skip bare `<li>` elements AND skip items containing `nav_a` class links
3. **Diagnostic logging** - Kept suspicious entry warnings (no cover AND no rating) as console warnings for future debugging

## Lessons Learned

1. **DOM inspection is essential** - When scraping fails, actual HTML from the page reveals issues faster than code inspection
2. **Page structure varies by Amazon page type** - Author pages, series pages, and product pages have different HTML structures and CDN domains
3. **Footer pollution** - Any page-wide scraper needs to explicitly filter navigation/footer elements

## User Tip Added

Set page filters to "English" and "Kindle" on the author page before importing - this filters out audiobooks, foreign editions, and non-Kindle formats at the source.
